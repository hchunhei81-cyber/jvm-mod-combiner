            已验证
            
Rust 启动器

            

              解析运行环境并启动独立 JVM，加载对应的 Minecraft 模组加载器。
            

            Rust + JNI
          

          

            02
            已验证
            
Java Agent

            

              在目标 JVM 中初始化 Agent，读取游戏实例并提取 Fabric 玩家状态。
            

            premain / Instrumentation
          

          

            03
            已验证
            
本地 TCP DataBus

            04
            概念验证
            
单向玩家镜像

            Fabric → NeoForge

CAPABILITIES

          
为 JVM 互操作而设计

          

            从启动流程到运行时通信，逐层构建跨模组生态的技术基础。
          

        

        

          
          6 项功能
        

        

          

            01 / CORE
            
RUST

            
Rust 启动内核

            

              解析版本依赖、组织 JVM 类路径，并通过 JNI 启动目标 Java 环境。
            

            已验证启动
          

          

            02 / AGENT
            
JVM

            
Java Agent

            

              使用 premain 和 Instrumentation 探索运行时类结构及诊断能力。
            

            初始化已验证
          

          

            03 / PLAYER STATE
            
STATE

            
Fabric 玩家状态读取

            

              通过反射读取玩家状态并发布到 Rust DataBus；Java 源码还包含敌对生物采样及初始/变化消息的早期原型。
            

            状态读取与发布已验证
          

          

            04 / TRANSPORT
            
TCP

            
Rust TCP DataBus

            

              Rust 源码按注册连接名限制玩家及怪物状态消息仅由 Fabric 发布；注册名仍由客户端自报，且拒绝行为待运行时验证。
            

            基础路由已验证
          

          

            05 / SYNC
            
SYNC

            
双端实体镜像

            

              Fabric 到 NeoForge 的 RemotePlayer 镜像已完成概念验证；实体身份、重连和世界切换恢复仍需稳定化。NeoForge 怪物接收端尚未实现。
            

            概念验证完成 · 持续稳定中
          

          

            06 / DEBUG
            
TRACE

            
运行时结构诊断

            

              输出 Minecraft 实例字段、类型和值，辅助分析混淆环境。
            

            基础诊断已验证
          

        

        

          没有找到匹配的功能。
